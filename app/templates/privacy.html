Privacy policy

What SiteScope stores, which services it uses, and how to have an audit removed. Last updated 19 October 2026.

What SiteScope stores

When you run an audit, SiteScope stores the website address you entered and the audit result, so that the report link keeps working. The result contains only public information from that website: page addresses, titles, status codes and the issues found. SiteScope has no accounts and does not ask for your name or email address.

Hosting and security

The site runs on a server in Microsoft Azure's Central India region and is served through Cloudflare, which processes every request to protect the site from attacks and may set a security cookie. The web server keeps standard access logs, which include IP addresses, for a short time for troubleshooting.

Crawling other websites

SiteScope's crawler identifies itself as SiteScopeBot and follows robots.txt. If you own a website and do not want it audited, add these two lines to your robots.txt:

User-agent: SiteScopeBot
Disallow: /

Removing an audit

To have an audit report removed, open an issue on the SiteScope GitHub repository with the report link, and it will be deleted.
