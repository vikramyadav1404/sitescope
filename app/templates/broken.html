What counts as a broken link

A link is broken when the URL returns a 4xx or 5xx status, or when the server cannot be reached at all. SiteScope tests links with a HEAD request and falls back to GET for servers that reject HEAD.

Internal vs external broken links

  • Internal broken links (warning) waste crawl budget and send visitors to error pages on your own site. Fix them first.
  • External broken links (notice) point to other sites that have moved or closed. Update or remove them.

How to fix broken links

  1. Open the audit report and find "Links to a broken internal URL".
  2. For each page listed, update the link to the correct URL, or remove it.
  3. If a page moved, add a 301 redirect from the old URL to the new one.
  4. Run the audit again to confirm the links are fixed.

Redirect chains

A link that passes through two or more redirects before reaching the final page is slower and can lose ranking signals. SiteScope reports these as redirect chains so you can link straight to the final URL.
