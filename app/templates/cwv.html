LCP, INP and CLS meaning

MetricWhat it measuresGoodPoor
LCP (Largest Contentful Paint)How long the biggest image or text block takes to appear2.5 s or lessover 4 s
INP (Interaction to Next Paint)How quickly the page responds to clicks, taps and key presses200 ms or lessover 500 ms
CLS (Cumulative Layout Shift)How much the layout jumps while loading0.1 or lessover 0.25

Thresholds are from Google's Core Web Vitals guide. SiteScope flags LCP above 2.5 s, INP above 200 ms and CLS above 0.1 as warnings.

How to improve each metric

  • LCP: compress and correctly size the hero image, preload it, and reduce server response time.
  • INP: split long JavaScript tasks and defer scripts that are not needed for the first interaction.
  • CLS: set width and height on images and embeds, and reserve space for banners and ads.

Field data vs lab data

Field data comes from real Chrome users over the last 28 days and is what Google uses. Small or new sites often have no field data, so SiteScope shows Lighthouse lab numbers instead and labels which source it used.
